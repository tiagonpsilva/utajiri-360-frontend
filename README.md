# Utajiri 360

## O Nome Utajiri 360

**Utajiri 360** é uma escolha estratégica que representa a essência completa do nosso produto:

✅ **"Mali"** - Do árabe, significa "riqueza" e "prosperidade"  
✅ **"360"** - Representa visão completa e controle total sobre suas finanças  
✅ **Visão completa** - "360°" transmite controle total sobre todas as áreas financeiras  
✅ **Nome impactante** - Curto, profissional e fácil de lembrar  

### Conceito da Marca
- **Dashboard 360** - Visão geral circular das finanças
- **Análise 360** - Todas as perspectivas financeiras integradas
- **Controle 360°** - Gestão completa do seu patrimônio

*"Utajiri 360 - Sua Riqueza em Perspectiva Total"*

## Descrição

Aplicação web para gerenciar orçamento pessoal, reunindo dados de diversas fontes bancárias, cartões de crédito, contas a receber, contas a pagar, investimentos. Esperamos que o usuário possa gerenciar o orçamento de forma simples e eficiente, com uma interface intuitiva e amigável. Ela deve servir também como uma ferramenta de planejamento financeira mensal, com previsões de gastos e receitas, e com alertas de gastos excessivos. Recomendações de ações para o usuário, com base em padrões de gastos e receitas. Lembretes de pagamentos, contas a pagar, contas a receber, etc.

## Funcionalidades principais

- Login com Google
- Importação de extratos bancários mensalmente

- Importação de dados de contas a pagar mensalmente
- Importação de dados de investimentos mensalmente
- Importação de dados de poupança mensalmente
- Categorização de receitas e despesas, de forma automática, com base em padrões de gastos e receitas.
- Gráfico de gastos por categoria
- Gráfico de receitas por categoria
- Visão de patrimônio
- Visão de fluxo de caixa
- Visão de despesas por categoria
- Visão de receitas por categoria
- Visão de investimentos
