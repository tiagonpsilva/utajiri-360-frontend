# Gestão do Projeto Utajiri 360

Este diretório contém toda a documentação de gestão do projeto, incluindo roadmap, user stories, enabler stories e tracking de atividades.

## Estrutura

- **roadmap/** - Planejamento estratégico e roadmap do produto
- **user-stories/** - Histórias de usuário organizadas por épicos
- **enabler-stories/** - Histórias técnicas e de infraestrutura
- **atividades/** - Log detalhado de todas as atividades executadas
- **milestones/** - Marcos importantes e entregas do projeto

## Processo de Trabalho

1. **Roadmap** - Definição do plano estratégico
2. **User Stories** - Criação das histórias de usuário
3. **Enabler Stories** - Definição das histórias técnicas
4. **Execução** - Desenvolvimento seguindo as stories
5. **Documentação** - Registro de todas as atividades

## Princípios

- Toda funcionalidade deve ter uma user story correspondente
- Toda atividade técnica deve ter uma enabler story
- Nada é desenvolvido sem passar pela organização prévia
- Documentação contínua de todas as atividades
